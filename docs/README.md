## 阅读顺序

开发前先读根目录 `AGENTS.md`。按任务选择本文档中的当前规范，不需要查找已删除的历史计划。

- 修改跨模块代码：架构总览 → 工程规范。
- 修改前端：UI 实现规则 → UI 设计规格。
- 修改自动写作：AI 协作规则 → 产品设计。
- 配置本地环境：本地开发指南。

## 维护规则

1. 文档路径变化时同步更新 `AGENTS.md`、`README.md` 和 `.cursor/rules`。
2. 架构事实只在“架构总览”维护，其他文档引用它，不复制整段目录说明。
3. 临时修复计划完成后删除；仍具长期价值的结论合并进架构或工程规范。
4. 不保留指向不存在文件、旧页面或旧目录的入口。
